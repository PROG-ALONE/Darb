# 📚 دَرْب — تطبيق مراجعة ومنهج تفاعلي للصف السادس الإعدادي (العلمي)

> **PWA** يعمل بلا إنترنت · يدعم الحساب بالخط اليدوي + الإدخال الرقمي · أهداف يومية · مراجعة متباعدة · إحصائيات تفصيلية

| الميزة | الوصف |
|---|---|
| **📖 محتوى كتابي كامل** | 9 فصول فيزياء · 8 كيمياء · 5 أحياء · 6 رياضيات · 6 وحدات عربية · 5 إنجليزية · 5 إسلامية — جميعها منقولة حرفيًا من الكتاب الرسمي |

| **🌙 ثيمات متعددة** | تلقائي / فاتح / ورقي / داكن / ليلي — مع خط عربي محسن |

## 🛠 التقنيات

- **Vanilla JS** (ES6 Modules) — لا اعتماديات خارجية
- **IndexedDB** للتخزين المحلي (المحتوى + صور الحلول + صور الحساب)
- **Service Worker** للتخزين المؤقت والاستخدام بلا إنترنت
- **CSS Variables** للثيمات الديناميكية
- **Arabic-Indic numerals** في النصوص، Latin في المعادلات

## 📂 بنية المشروع

```
darb/
├── index.html          # التطبيق الكامل (HTML + CSS + JS في ملف واحد)
├── sw.js               # Service Worker (إصدار الكاش: darb-v39)
├── manifest.webmanifest
├── icon-192.png, icon-512.png
├── content/            # ملفات المحتوى (فصل لكل ملف)
│   ├── physics-12-c1.js ... c9.js
│   ├── chemistry-12-c1.js ... c8.js
│   ├── biology-12-c1.js ... c5.js
│   ├── math-12-c1.js ... c6.js
│   ├── arabic-12-u1.js ... u6.js
│   ├── english-12-u1.js ... u5.js
│   └── islamic-12-u1.js ... u5.js
├── wire.mjs            # أداة ربط المحتوى بـ index.html + تحديث sw.js
├── context/            # سياقات العمل المتوازي للفرق
└── PROJECT_MAP.md      # خريطة شاملة للمشروع
```

## ⚙️ التطوير المحلي

```bash
# استنساخ
git clone https://github.com/PROG-ALONE/darb.git
cd darb

# خادم محلي (أي خادم ثابت يعمل)
npx serve .          # أو: python3 -m http.server 8770
# ثم افتح http://localhost:8770/?t=Date.now() لتجاوز الكاش

# التحقق من صيغة أي ملف محتوى
node --check content/physics-12-c6.js

# إضافة محتوى جديد → تشغيل wire.mjs
node wire.mjs content/physics-12-c10.js
```

## 🌐 النشر على GitHub Pages (Portfolio)

1. اذهب إلى **Settings → Pages** في مستودع `PROG-ALONE/darb`
2. **Source**: اختر `Deploy from a branch`
3. **Branch**: `main` / `/ (root)`
4. اضغط **Save** — سيظهر الرابط خلال دقائق: `https://PROG-ALONE.github.io/darb/`

> **ملاحظة:** التطبيق PWA سيعمل تلقائيًا على GitHub Pages لأن `sw.js` يستخدم مسارات نسبية (`./`). أيقونة التثبيت والـ manifest جاهزان.
