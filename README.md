# دَرْب

**طريقك من الأول الابتدائي إلى السادس الإعدادي، تفهم فيه قبل أن تحفظ.**

تطبيق دراسي عربي مجاني لكل طالب عراقي. يُفتح من المتصفح ويُثبَّت على الهاتف كتطبيق، ويعمل بلا إنترنت بعد أول فتح. المحتوى من الكتب الوزارية المعتمدة، وكل موضوع يذكر صفحته في الكتاب.

🔗 **ادخل التطبيق:** https://prog-alone.github.io/darb/

---

## الفكرة

الدَّرْب هو الطريق الذي يُسلك خطوة بعد خطوة. لكل مادة مسار متعرّج: محطاته الفصول ثم المواضيع، وبعد كل موضوع اختبار. الطالب يعرف دائمًا أين وصل وما الخطوة التالية.

المبدأ: الحفظ بلا فهم يُنسى، والمعدل العالي نتيجة طبيعية للفهم. لذلك يبدأ كل موضوع بسؤال «لماذا ندرسه؟» قبل أي تعريف أو قانون.

## كيف يدرس الطالب

| # | الخطوة | ما فيها |
| --- | --- | --- |
| ١ | المسار | الفصول والمواضيع على طريق واحد، مع نسبة الإنجاز لكل محطة. |
| ٢ | لماذا ندرسه؟ | سبب دراسة الموضوع وصلته بالحياة. |
| ٣ | الشرح | نص الكتاب كما هو، مع رسوم ومحاكاة تفاعلية تغني عن الفيديو، ورابط اختياري لشرح على يوتيوب. |
| ٤ | التثبيت | التعاريف، القوانين، التعليلات، املأ الفراغ — كلٌّ في تبويب. |
| ٥ | التطبيق | أمثلة الكتاب خطوة بخطوة، ومسائل موقوتة لا يظهر حلها إلا بعد انتهاء الوقت. |
| ٦ | الحفظ | للنصوص المقررة فقط: اقرأ وكرّر، إخفاء تدريجي بخمسة مستويات، بطاقات، واختبار حفظ لا يُجتاز إلا بـ١٠٠٪. بداية الحفظ ونهايته معلَّمتان داخل الشرح. |
| ٧ | الاختبار | اختبار بعد كل موضوع، واختبار شامل لكل فصل، وكل جواب معه سببه. |
| ٨ | الدفتر | حلول الطالب وملاحظاته وأخطاؤه مرتبة لكل مادة، وتُصدَّر دفترًا أو تقريرًا بستة مستويات (درس، تبويب، فصل، مادة، صف، كامل). |

## مزايا أخرى

- **أكثر من طالب على الجهاز نفسه**، لكلٍّ تقدّمه ودفاتره.
- **خطة دراسية** من تاريخ بدء الدوام والوقت اليومي وموعد الامتحان والمعدل المستهدف.
- **إخفاء المواضيع** غير المقررة على الطالب أو الخاصة بفرع آخر.
- **بحث شامل** في المواضيع والتعاريف والقوانين والتعليلات.
- **خمسة أنماط عرض** (تلقائي، فاتح، ورقي، داكن، ليلي) وخمس درجات لحجم الخط.
- **نسخ احتياطي واسترجاع** بملف أو نص.
- **الخصوصية:** البيانات على جهاز الطالب فقط، بلا حساب ولا رقم هاتف، وبلا إعلانات ولا اشتراكات.

## التثبيت على الهاتف

- **آيفون/آيباد:** افتح الرابط في Safari ← «مشاركة» ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← «تثبيت التطبيق».

## البنية التقنية

تطبيق ويب تقدّمي (PWA) بملف HTML واحد، بلا خادم ولا مكتبات خارجية.

| الملف | الغرض |
| --- | --- |
| `index.html` | التطبيق كاملًا: الواجهة والمنطق والتصميم |
| `content/h.js` | أدوات بناء المحتوى المشتركة |
| `content/<مادة>-<صف>-<فصل>.js` | محتوى كل فصل، مثل `physics-12-c1.js` (فيزياء السادس، الفصل الأول) |
| `sw.js` | حفظ الملفات للعمل بلا إنترنت؛ يُغيَّر رقم `CACHE` مع كل تحديث |
| `manifest.webmanifest` | الاسم والأيقونة عند التثبيت |
| `icon-192.png`, `icon-512.png` | الأيقونة |

## سجل الإصدارات

**الإصدار ١ — تشرين الأول ٢٠٢٦**
- الهيكل: أول فتح بقصة قصيرة، تعدد الطلاب، ستة تبويبات، الإعدادات، العمل بلا إنترنت.
- المسار المتعرّج للمواد والفصول، والرجوع إلى موضع الطالب عند الخروج من موضوع.
- الفصل الأول من كل مواد السادس العلمي (عدا الفرنسي)، والفصل الثاني من الفيزياء.
- الدفتر والتصدير، الحفظ على نمط «ذُرى»، ورابط يوتيوب اختياري لكل موضوع.
