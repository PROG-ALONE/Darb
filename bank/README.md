# بنك الأسئلة — السادس الإعدادي (الفرع العلمي)

مجلد البنك المستقل: نسخة قابلة للقراءة والسحب والمعالجة **خارج التطبيق**، مع نسخة مطابقة تُخدم داخل التطبيق.

## الملفات

| الملف | الوصف |
|---|---|
| `all-questions.json` | بنك آلي كامل: 151 سؤالًا + `meta` + `summary` + كل سؤال بـ `tid/q/o/c/why/src/year`. |
| `بنك-الأسئلة.md` | نفس البنك بصيغة مقروءة مرتّبة **مادة ← فصل ← موضوع**، مع الجواب الصحيح والحل. |
| `README.md` | هذا الملف. |

النُّسخة التي يعمل بها التطبيق موجودة في `content/ministerial-*.js` (تُغذّي `window.MINISTERIAL_BANK`)، والملفان هنا مولّدان منها فلا يعتمد عليهما التطبيق.

```json
{
  "subjectKey": "12:sci:الفيزياء",
  "subject": "الفيزياء",
  "n": 1,
  "tid": "p12c1t1",
  "q": "نص السؤال…",
  "o": ["خيار", "خيار", "خيار", "خيار"],
  "c": 0,
  "why": "الحل التفصيلي",
  "src": "wizarati",
  "year": 2024
}
```

## كيف تسحب/تقرأ البنك؟

- **للقراءة البشرية:** افتح `بنك-الأسئلة.md`.
- **للمعالجة البرمجية/الاستيراد:** اقرأ `all-questions.json`.
- **من الطرفية (مثال سريع):**
  ```bash
  node -e "const b=require('./bank/all-questions.json');console.log(b.questions.length+' سؤال');console.log(b.questions.filter(q=>q.subject==='الفيزياء')[0].q)"
  ```
- **عرض حسب الفصل:** كل سؤال فيه `tid` مثل `p12c2t4`؛ البادئة `p12c2` تعني «فيزياء، فصل ٢»، واللاحقة `t4` موضوع ٤.

## حالة المصدر (صدق)

- **وزارياتي (`wizarati.app`):** 66 سؤالًا حقيقيًا مع حلولها (سنة الدورة واسم الفصل)، مستخرجة من صفحات الأسئلة المفردة.
- **المولّد:** بقية الأسئلة (85) نموذجية على نمط الوزاري (دورات ٢٠١٦–٢٠٢٦)، محرَّرة يدويًا في المشروع.
- **المحجوب:** وزارياتي يعرض ٤٦٤ سؤالًا، منها ٦٦ فقط للزائر. الأسئلة الـ ٣٩٨ الباقية تحتاج حسابًا مجانيًا مسجّلًا.

## أداة استكمال الأسئلة المحجوبة (جاهزة)

هناك مساران:

1. **جلسة مسجّلة في متصفح OpenCode:** سجّل الدخول إلى `wizarati.app` في تبويب المتصفح، ثم تُقرأ كل صفحة فصل (٢٢ فصلًا) وتُستخرج جميع الأسئلة وحلولها من الصفحة المعروضة.
2. **نقطة نهاية Convex مع رمز Clerk:** الموقع يبني على `convex.cloud`؛ الدالة `questionBank` محجوبة بالمصادقة. عند توفر رمز الجلسة يمكن نداء الاستعلام مباشرة.

> بمجرد توفّر جلسة مسجّلة، يكفي تشغيل خط الاستخراج نفسه (`scrape-all.mjs` في نطاق العمل المؤقت) ثم إعادة الدمج ليكتمل البنك إلى ٤٦٤+ سؤالًا بحلولها.
