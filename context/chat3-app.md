## 🎯 نطاق عملك (حصريًا)
### المهمة ١ — نظام المطابقة الجديد (الأولوية القصوى)
المستخدم لا يقبل إظهار الجواب فورًا عند الخطأ. **التدفق المطلوب** (على كل ما فيه إجابة رقمية نهائية):
1. الطالب يضغط **«ابدأ الحل»** → يبدأ المؤقت، ويظهر له **خطوات الحل بالترتيب والتفصيل** (النموذج/المنهج: القانون، ترتيب الخطوات، ما يُحسب في كل خطوة) — **لكن الرقم النهائي العددي مخفي** (يظهر كـ `؟` أو `[جواب]`) حتى لا ينسخ مباشرة. الخطوات تكون مفصّلة لا مختصرة.
2. الطالب يحل **في دفتره** بالخطوات المرشدة.
3. الطالب **يُدخل رقم جوابه النهائي** باللوحة الرقمية (٠-٩ + `.` `/` `-` + وحدة قياس).
4. **إذا صح** (يطابق الرقم النهائي):
   - يظهر **الحل المضبوط كاملًا** (الخطوات + الجواب النهائي المرئي).
   - **يبدأ احتساب الوقت** الفعلي (كم استغرق من المقترح) و**تفاصيل تؤثر على هدفه وطريقة دراسته** (مثلاً: حلّلت بدقيقة من مقترح دقيقتين → تقدّم تاريخ هدفك / يُضاف لك وقت إيجابي؛ أو تأخرت → يُعدّل). حدّد أثر الوقت على `goal`/`targetDate`.
   - يُسجَّل كـ«مُتقن».
5. **إذا خاطئ**:
   - يُضاف الموضوع **للمراجعة** (rev) ويظهر **الحل الكامل**.
   - يُسجَّل الوقت ونسبة الدقة.

**النطاق**: «كل ما فيه إجابة رقمية نهائية» → مسائل الفصول (`vProblem` + `problems`) + الأمثلة المحلولة (`examples`) + أي سؤال اختبار بأرقام. (أسئلة الاختيار/صح-خطأ النصية تبقى كما هي.)

**تنفيذ مقترح** (في `index.html`):
- أضف `steps` كمرجع للعرض مبكرًا مع إخفاء الرقم النهائي (أو استخدم `p.steps` مع استبدال أي رقم نهائي بـ `؟`). حاليًا `vProblem` تعرض لوحة الأرقام؛ عدّلها لعرض الخطوات أولًا (مرحلة «الترشيد») ثم مرحلة «المطابقة».
- وحّد المقارنة بـ `normA()` (توحيد عربي/لاتيني، إزالة مسافات، قبول ±هامش، قبول كسور مكافئة). عدّل `case 'ansSubmit'`.
- أضف `case` جديد لـ «كشف الجواب يدويًا» (زر «لا أعرف») → يكشف فورًا ويُسجَّل خطأ.
- اجعل الأمثلة المحلولة قابلة للاختبار بنفس الآلية.

### المهمة ٢ — توسعة الميزات (ثانوية)
1. **فلاتر سجل المراجعة**: `reviewLogHTML()` تعرض حاليًا آخر ٣٠ يومًا — أضف فلاتر **يوم/أسبوع/شهر/فصل/نصف سنة/سنة** مع سحب التفاصيل لكل فترة.
2. **«اختباراتي» غير العشوائي**: تعرض كل المواد، والطالب يدخل يختبر **بفصل معيّن بكل مواضيعه** (بدل الاختيار العشوائي). أضف شاشة تفاصيل أعلى كل تبويب عند الضغط يظهر سجل (شاشة + سجل على كل التبويبات التي تحتاج).
3. **تبويب تصدير مجمّع في الإعدادات** (يوجد `reports` في `SET_TABS`) — وسّعه ليُنتج **ملفات مقسمة حسب كل تبويب** + تقارير حسب المواد والفصول.

### المهمة ٣ — الدمج النهائي (بعد اكتمال المحتوى)
عندما تُبلَّغ بأن محادثتَي ١ و٢ أكملتا المحتوى:
```bash
cd /Users/macbookair/Downloads/darb-main
# 1) اربط كل المحتوى الجديد
node wire.mjs content/physics-12-c6.js content/physics-12-c7.js content/physics-12-c8.js content/physics-12-c9.js content/math-12-c3.js content/math-12-c6.js content/biology-12-c3.js
# 2) تحقق صيغة index.html
python3 -c "import re;c=open('index.html',encoding='utf-8').read();m=re.findall(r'<script>([\s\S]*?)</script>',c);open('/tmp/c.js','w',encoding='utf-8').write(m[-1])" && node --check /tmp/c.js && echo OK
# 3) ارفع CACHE في sw.js إن لم يفعله wire.mjs تلقائيًا (هو يفعله)
```

## 📚 الملفات والمرجع
- `index.html` — التطبيق كله (٢٧٠KB+). **استخدم `grep` للعثور على المواضع** بدل قراءته كاملاً. مواقع رئيسية: `vProblem` (~L2700)، `vToday` (~L725)، `vReview`، `vTests`، `SET_TABS`/`vSettings` (~L1109)، `case 'acc'`/`'ansNum'`/`'ansSubmit'` في dispatcher، `accSec`.
- `sw.js` — `CACHE='darb-v34'`، قائمة `CORE`.
- `wire.mjs` — ربط المحتوى (يعدّل index.html + sw.js + يرفع CACHE).
- `content/h.js` — أدوات المحتوى (`window.H`).
- مرجع أساليب: `content/biology-12-c4.js`، `content/physics-12-c5.js`.

## 📝 قواعد تقنية (إلزامية)
- **`edit` يفشل أحيانًا مع العربية** في `index.html` → استخدم بايثون بايت-دو-بايت مع `<<'PYEOF'`:
  ```bash
  python3 - <<'PYEOF'
  d=open('index.html','rb').read(); d=d.replace(b'OLD',b'NEW',1); open('index.html','wb').write(d)
  PYEOF
  ```
- **تحقق دائمًا** بعد أي تعديل: `node --check /tmp/c.js` (استخراج آخر `<script>`). أخطاء CSS-داخل-JS وقعت سابقًا — انتبه.
- أضف أنماط CSS الجديدة **داخل `<style>`** وليس داخل `<script>`.
- `setTimeout` غير متاح داخل `browser.evaluate` — استخدم حلقات أو `location.reload()`.
- اختبر بـ tab جديد + `?t=Date.now()` لتتجاوز الكاش، وتحقق `console.messages === []`.
- لا تنشور PAT أو بيانات اعتماد.
