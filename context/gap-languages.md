## 🔧 نمط ملف وحدة جديدة (مطابق لـ u1)
أنشئ الملف بالقالب نفسه حرفيًا، غيّر `N` و`id` والعنوان:
```js
/* <المادة> — السادس الإعدادي (العلمي والأدبي) — الوحدة N: <العنوان> (الكتاب صX–Y).
   النصوص منقولة من الكتاب؛ أجوبة التمرينات من إعداد التطبيق وفق قواعد الكتاب نفسها. */
(function () {
  const { Q, TF, X, B, T, L, D, R, F, E, P, K, N, EQ, HD, LI, TH, TB } = window.H;
  const topics = [
    T({ id: '<-prefix>12uNt1', sec: 'المطالعة', page: 'X', title: '<عنوان النص>', en: '<en>',
      why: '<لماذا يهم هذا النص/الدرس>',
      explain: [ P('نص المطالعة كاملًا...'), HD('ما بعد النص'), TB('معاني المفردات', ['الكلمة','المعنى'], [['..','..']]), TH('نشاط: ..', '..') ],
      defs: [ D('..', '..') ],
      examples: [], problems: [],
      quiz: [ Q('..', ['..','..','..','..'], '..'), TF('..', true, '..') ] }),
    // ... بقية مواضيع الوحدة: قواعد النحو/الصرف، البلاغة، الإملاء، التعبير، القراءة
  ];
  window.H.push(['12:sci:<المادة>', '12:lit:<المادة>'], { id: '<prefix>12uN', no: N, title: 'الوحدة N: <العنوان>', en: 'Unit N', pages: 'X–Y', goals: [], terms: [], test: { title: 'اختبار الوحدة N', useTopicQuiz: true }, topics });
})();
```
** prefixes ومفاتيح مادتك:**
- العربية: `id` مثل `r12u2`، مواضيع `r12u2t1..`، المفاتيح `['12:sci:اللغة العربية','12:lit:اللغة العربية']`
- الإنكليزية: `e12u2` / `e12u2t1..`، المفاتيح `['12:sci:اللغة الإنكليزية','12:lit:اللغة الإنكليزية']`
- الإسلامية: `i12u2` / `i12u2t1..`، المفاتيح `['12:sci:التربية الإسلامية','12:lit:التربية الإسلامية']`

**محتوى كل وحدة لغوية** (حسب ما في الكتاب): نص المطالعة · قواعد النحو/الصرف (شرح + أمثلة) · البلاغة · الإملاء · التعبير/الكتابة · القراءة الوظيفية · والتمرينات (بمعرّفات فريدة `<prefix>12uN-*`). أضف `examples`/`problems` للتمارين الرقمية/الإملائية إن وُجدت، و`Q`/`TF` بسب `why` لكل وحدة.
