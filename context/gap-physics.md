## 🔧 كيف تعدّل ملفًا قائمًا
افتح الملف، وجد مصفوفة `const topics = [ T({ id:'p12cNtM', ... }), ... ]`. داخل كل `T({...})` أضف/وسّع:
- `examples: [ E('عنوان', 'صفحة', 'نص المسألة المحلولة', [خطوات], 'الجواب') ]` — مثال محلول خطوة بخطوة
- `problems: [ B('p12cNtM-pK', 'صX', '3-2', 'نص المسألة', 'الجواب', [خطوات اختياري]), X(...) ]` — مسألة كتاب `B` أو تدريب `X`
- إن رأيت `quiz` فارغًا فأضف `Q('..',[..],'..')` و`TF('..',true,'..')` بسب `why`.

**معرّفات فريدة**: مسائل الفصل تبدأ `p12c6-*` / `p12c7-*` / `p12c9-*` متبوعًا برقم الموضوع والمسألة (مثل `p12c7t3-p1`).
لا تُكرّر معرّفًا موجودًا. لا تُحسِّن/تصفّح مواضيع قديمة بأكملها — أضف فقط التدريب الناقص.

## 📐 نمط الأدوات (من `content/h.js`)
```js
B(id, ref, sec, text, ans, steps)   // مسألة من الكتاب: ref=رقم/صفحة الكتاب، sec=رقم الوضع، ans=الجواب النهائي، steps=خطوات
X(id, sec, text, ans, steps)        // تدريب إضافي من إعداد التطبيق
E(title, page, text, steps, ans)    // مثال محلول: steps=مصفوفة خطوات الحل
Q(q, [choices], why)  TF(q, true, why)   // اختيار متعدد / صح-خطأ بسبب
```
- الأرقام في النصوص: **عربية-هندية** (٠١٢٣…). داخل المعادلات والوحدات: **لاتينية** (F = BIL, N, Ω).
- كل `Q`/`TF` يجب أن يحوي `why` (سبب).
- لا تكتب حرفي `\n` ولا TODO ولا `</longcat_think>`.
- داخل `steps` و`ans` استخدم صيغة الكسور `\\frac{}{}` و`^{}` كما في الملفات القائمة.
