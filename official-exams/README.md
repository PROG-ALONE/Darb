# أرشيف الوزاري الرسمي — السادس العلمي (2020–2026)

أرشيف كامل مرتّب لأسئلة الامتحانات الوزارية **السادس العلمي**:

- **الأسئلة** من الموقع الرسمي [iraqedu.net](https://iraqedu.net) (صور صفحات الأسئلة كما تنشرها الوزارة).
- **الحلول النموذجية** من بوت تلغرام **@EDIRQBot** (الملفات الرسمية المرافقة لأسئلة الدورات).

## البنية

```
official-exams/
├── questions/                    أسئلة الوزاري (صور صفحات الموقع)
│   └── <المادة>/<السنة>/<الدور>/…
├── solutions/                    الحلول النموذجية (PDF)
│   └── <المادة>/<السنة>/<الدور>/…
├── manifest.jsonl                جرد كل صفحة: slug ← {المادة، السنة، الدور، الصور، startIds}
├── bot-ids.json                  كامل معرّفات أزرار التحميل (123 معرّفًا)
├── questions-count.txt           عدد صور الأسئلة (247)
├── solutions-manifest.json       جرد الحلول: المعرّف ← صفحة الموقع / ملف البوت / الحالة
└── README.md                     هذا الفهرس
```

- **النطاق:** السنوات **2020–2026**، بالأدوار المتوفرة: الدور الأول / الدور الثاني / الدور الثالث / التمهيدي / التكميلي.
- **الأسئلة** تشمل 8 مواد (الست أدناه + الإسلامية والإنكليزية). **الحلول النموذجية** للمواد الست:
  أحياء، كيمياء، فيزياء، رياضيات، عربي، فرنسي.

## منهجية الجمع

1. لكل صفحة أسئلة زر «تحميل الحل» يحمل معرّفًا (`start id`).
2. يُرسل للبوت أمر `/start <المعرّف>` ويُحمَّل ملف الرد.
3. التنزيل **تسلسلي صارم** (نقرة واحدة ← حصاد ملفها ← النقرة التالية) مع اعتراض
   `URL.createObjectURL`؛ كل نقرة تُنتج نسختين متطابقتين من الملف فيُستهلك الأول ويُتخطّى التوأم
   بنفس الحجم (منعًا لخلط محتويات ملفين).
4. عند خلاف بين الموقع والبوت: **يُعتمد اسم ومحتوى ملف البوت**، ويُوضع الملف في المكان الذي
   يمثله فعليًا، ويُوثَّق التعارض في `solutions-manifest.json` (حقل `note`).

## ملاحظات

- ملفات البوت العامة (مثل `اجوبة.pdf`، `الاجوبة.pdf`، `asd` …) أُعيدت تسميتها بأسماء مقروءة
  تدل على النسخة (مثل `اجوبة_الفرنسي_2021_الدور_الاول.pdf`) بعد التحقق من محتواها.
- ملف **عربي/مجمعة-سنوات** (96.5 MB — «نسخ الأسئلة الوزارية من سنة 2014») هو ردّ البوت للمعرّف
  المشترك 1725966539 الذي تخدمه صفحات عربي 2020–2022 معًا.
- `solutions-manifest.json` هو مصدر الحقيقة: جرد كل معرّف ← صفحة الموقع، ملف البوت، الحجم،
  والحالة (`ok` / `duplicate` / `mismatch`).
