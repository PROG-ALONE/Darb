## الاستخدام

### قراءة البنك المنظم
```bash
# ملخص سريع
node extract-solutions.cjs

# استخراج عبر Gemini (أسرع وأدق)
GEMINI_API_KEY=... node extract-gemini.cjs 1
```

### الوصول للبيانات
- **للقراءة:** `batches-md/*.md` — 36 ملف Markdown
- **للمعالجة:** `bank-extracted.json` — JSON كامل (1.98MB)
- **للدمج مع التطبيق:** `content/ministerial-*.js`

## ملاحظات الجودة

- جودة OCR متفاوتة: الكيمياء ممتازة، العربية/الفرنسية جيدة، الفيزياء جزئية
- الرياضيات والأحياء: صفحات مصوّرة بلا طبقة نصية (تحتاج OCR دقيق)
- الحلول النموذجية مختلطة مع الأسئلة في بعض الملفات
- الاستخراج عبر Gemini يعطي نتائج أدق لكن محدود بالمعدل (429)
