قراءات اللغة العربية : ( ٤٠ درجة )

أ) قال تعالى : ( وَقَالَ الرَّبِّ انْظُرْنَا أَنْزِلْنَا لَوْ عَنَّاكَ أَنْهُ لَمْ نَكُنْ نَظُرِيهِ مِن قَبْلُ وَمَا نَحْنُ بِمُؤْمِنِينَ ).
استخرج التوكيد الواقع في النص الكريم .
ب) قال رسول الله (ص) : ( مَا أَمَنْ بِي ، مَنْ بَاتَ شُبْعَانَ وَجَارَةُ جَانِقِ )
عيّن أداة النفى ، وبيّن زمنها المنفي وأعربها .
ج) قال الشاعر ( أحمد شوقي ) : مَا بِالُ العائِلِ . يُنْفَعُ لِي / بِابُ السُّلَوانِ وأَوْسِدَةُ
حدّد اسم الاستفهام وأعربه مع ذكر السبب .
د) قال الشاعر ( أبو الحسن التلهامي ) : لا حَذَّنَّ الشَّيْبَ الوَفْيُ وحيداً / شَرَحَ الشَّيَابُ الخَاتِمُ الغُدَارُ
في البيت أسلوبٌ مَدْحٌ وأسلوبُ ذمٍ ، استخرججهما ، ثم أعرب المخصوص بالدَّم .
هـ) قال الشاعر ( ابن زَيْدُون ) : يا بَانِعًا حُظَّةً مِنِّي وَلَو بَذَلْتَ / لِي الحياةَ بخطِّي منه لم إبقَ
ما دلالة أداة النداء ؟ ثم استخرِجَ المَنادى وبَيِّن نوعه.
و) قالت ( الخنّساء ) : ما لِلمُتَ النَّبَا تَعَادِينا وتُطِرِقُنا / كَأَنَّنا أَبَداً تَحَرَّ بالفأس.
في البيت تعجُّب استخرجه ، وبيّن نوعه وصيغته .
ز) تقول : ( صِفات مَن تُحِبّ ).
كيف تعرب اسم الاستفهام معللاً ؟
س٢ : أ) قال تعالى : ( قَالُوا يَتَنَزَّهُ لَقَدْ جِئْتَ بِكَ حَقًّا بَأَغْتَدْ كُرْبَةٍ مَا كَانَ أُولَٰئِكَ أَحَرَّزَ سِغَرًا ).
في النص مناديان عينهما وأعرب الأول . ( ٢ درجات )
ب) أجب عن أولا أو ثانيا :
أولا : قال الشاعر ( بهاء الدين زهير ) : لِي في الغُرام سَريِرَةٌ / وَاللهُ اعْلَمْ بالسرائر
ما حكم تقديم الخبر ؟ ولماذا ؟ وكيف تجعل الحكم مغايراً ؟ ( ٢ درجات )
ثانيا : قال الشاعر ( أبو العتاهية ) : لا بَارِكَ اللهُ فيمَن كان بِخَيْرِني / أَنَّ المحبين في لهوٍ ولعبِ
ما نوع ( لا ) ؟ وما الذي أفادته ؟ وما الزمن الذي نفته ؟
جـ) ١) قال الشاعر ( الأبيوردي ) : فَطَلَّ يَرِيني الحُطْبَ كَيْفَ اعْتَدَاهُ / وَرَدَتْ ( كَيْف ) مَرَّتِينَ
ما إِعرابُها في كلِّ مَرَّةٍ معللاً ؟
٢) قال الشاعر ( ابن زَيْدُون ) : صَبا لعلَّ الذي بالبُعْدِ أَمْرَضَني / سَمَّ الطَّلَبُ وَبيِّنَ أَدَاتَهُ .
٣ - أ) قال تعالى : ( لَهُ مَا فِي السَّمَاوَاتِ وَمَا فِي الْأَرْضِ مَن ذَا الَّذِي يَشْفَعُ عِنْدَهُ
سَمُّ الطالب وبين أداتَهُ .
( درجتان ) ( ٤ درجات )
وبِئْتُ ارْبَةَ الصَّبْرِ كيف يكون / بالثَّقْبِ يَوْمًا يداوي فيشفِني ( درجتان )
س٣ : أ) قال تعالى : ( وَمَن يَصْلِ اللَّهَ فَهُوَ أَنْتَجَى مِن وَكِيلٍ مِّنْ يَشْتَدِيدِه ).
١) في النص ممنوعٌ مقعولٌ به مَقْدَّم ، عيّنه وبين حكمه والسبب .
٢) أعرب ما تحته خط . ( ٣ درجات )
ب) أجب عن ( اثنتين ) فقط ، ولكل واحدة ( ثلاث ) درجات .
١) قال الشاعر ( عروة بن الورد ) : هَلَا سَأَلْتَ بَنِي عِيلانَ كُلَّهُمْ / ما إعراب ( كُلَّهُمْ ) ؟ وما المعنى الذي قَاتَلَتْه ( هَلَا ) ؟
٢) قال الشاعر ( بشّار بن برد ) : وَلَسْتُ أُرِي إذا شِطَ المُزَارُ بهمْ / عَيْنٌ فَعَلَّا" للنفي ، ثم اذكر معموليه .
٣) قال الشاعر ( أبو العلاء المعري ) : ما أَطِيبَ الموتَ لِشَرَّابِه / طَيِّقَ المُصِيفَةِ الثانيةَ للعَشَبِ
إنَّ صَحَّ لِلأَصْواتِ وشَكَّ النقَاءُ / إِذَا صَفَّ لِلأَصْواتِ وَشَكَّ النِّقَاءُ
إلاَّ سَنِينَه كَبِيرَ رِجَاءِ / عندَ السَّنين إذا ما هَبَّتِ الرِّيحُ
هل تجمع الدار أم لا تُجمِعُ / عندَ السَّتين إذا ما هَبَّتِ الرِّيحُ
طبِّقَ المُصِيفَةَ الثانيةَ للعَشَبِ ، ثم أعرب الفاعل في الصَّيْفَيْنِ . ( ٦ درجات )
جـ) قال الشاعر ( عمرو بن أبي ربيعة ) : ما كنتُ أرجُو أنْ يُلِمَّ بِرِضَنا / أَكَدَّ النَّفِي بِحَرْفِ تَوَافِرَتِ شُرُوطُهُ مَعَ إِعرابِ ما يتَّصِلُ به .
