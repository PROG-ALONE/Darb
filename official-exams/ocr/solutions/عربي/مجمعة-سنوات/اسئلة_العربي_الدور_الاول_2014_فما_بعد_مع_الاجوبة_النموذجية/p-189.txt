الأدب والنصوص :
س٤ : أ) شاعر عراقي درس الفقه وأصوله ، دافع عن وطنه ضد البريطانيين ، اشتهر بموشحاته ، مَنْ الشاعر ؟
وفيمَ كانت قصيدته ؟ اكتب له ثلاثة أبيات منها مضبوطة بالشكل .
( ٥ درجات )
ب) أجب عن أولاً أو ثانياً :
( ٤ درجات )
أولاً : لماذا سُميَت جماعة ( أبولو ) بهذا الاسم ؟ ومَنْ مؤسسها ؟ وبمَ تأثر ؟ وما الذي حواه شعره
الرومانسي ؟
ثانياً : ما قصيدة النثر ؟ ومَنْ تبناها ؟ ومَن أبرز شعرائها ؟ وبمَ تميّزت ؟
ج) ما أبرز دوواين الشاعرة ( فدوى طوقان ) ؟ وكيف عالجت موضوعها ؟ وكيف كانت معانيها ؟ ( ٤ درجات )
س٥ : أ) للشاعر ( ميخائيل نعيمة ) قصيدة في منهجك المقرر ، ما عنوانها ؟ وبمَ يؤمن فيها ؟ وكيف كان
أسلوبها ؟ اكتب مقطعاً منها .
( ٥ درجات )
ب) ما نوعا السيرة ؟ وما أبرز سماتها وكتّابها ؟
( ٤ درجات )
ج) أولاً : ما ذروة ما وصل إليه الصراع في المشهد المسرحي من مسرحية ( ثانية يجيء الحسين )
( درجتان )
لمحمد علي الخفاجي ؟
( ٣ درجات )
ثانياً : عرّف ( الحبكة ) ، وبمَ ترتبط ؟
س ٦ : أ) هات أبياتاً تناسب ما يأتي :
١) ( البارودي ) استخدم أسلوب الاستفهام في قصيدته .
( درجتان )
( درجة واحدة )
٢) ( الجواهري ) أشاد باللغة العربية .
( درجة واحدة )
٣) ( مصطفى جمال الدين ) يحذّر ( بغداد ) من مؤرخ يكتب لسلطة البطش .
( درجة واحدة )
٤) ( السيّاب ) استهل قصيدته بمخاطبة امرأة غير واضحة الملامح .
( ٣ درجات )
ب) أجب عن أولاً أو ثانياً :
أولاً : للشاعر الزهاوي قصيدة تعليمية ، ما عنوانها ؟ وعمّ يتحدّث فيها ؟
ثانياً : من أهم خصائص المقالة ( الأسلوب الخاص ) ، وضّح ذلك .
( درجتان )
ج) ١) هل نجحت الشاعرة ( نازك الملائكة ) في توظيف البحر الكامل ( متفاعلن ) ؟ ولماذا ؟
( ٣ درجات )
٢) ما عنوان قصيدة ( حافظ إبراهيم ) ؟ وماذا يمجّد فيها ؟
( ٢٠ درجة )
الإنشاء :
س٧ : اكتب في أحد الموضوعين الأتيين :
فالمرء يسلم باللسان ويعطب
١) قال الشاعر : واحفظ لسانك واحترز من لفظه
اللسان مفتاح كل خير وشر ، فزينه بالحق واحفظه من الباطل .
وعزّ نفسك إن فارقت أوطانا
٢) قال الشاعر : اقنع بحظك في دنياك ما كانا
القناعة من أجمل صفات المؤمن وبها يصل إلى الحياة الطيبة السعيدة .
