الأدب والنصوص :
س٤ : أ) لمصطفى جمال الدين قصيدة في منهجك المقرر ، ما عنوانها ؟ وما مناسبتها ؟ وبمَ امتاز شعره ؟
( ٥ درجات )
استشهد له ببيتين منها مضبوطة بالشكل .
( ٣ درجات )
ب) أجب عن أولاً أو ثانياً :
أولاً : بلغت الخطابة ذروتها في عصر النهضة الحديثة ، وضح ذلك .
ثانياً : ما حال الأدب في عصر التدوين ؟ وفيمَ تمثل أثر ذلك ؟
( درجتان )
ج) ١) كيف كان خطاب ( فدوى طوقان ) لوطنها ؟ وعلامَ حثته ؟
( ٣ درجات )
٢) بمَ يستعرض الكاتب ( علي جواد الطاهر ) تجربته في الكتابة ؟ وبماذا يعترف ؟
( ٤ درجات )
س١ : ٥) ما المدلول اللغوي للمفردات الاتية ؟ ثمّ ردها إلى ابياتها المناسبة ( لاثنين فقط ) .
القدّ ، اللدات ، الجور .
ب) ( السيّاب ) و ( نازك الملائكة ) ، نظما قصيدتيهما على تفعيلة البحر الكامل ( متفاعلن ) ، فما
( ٤ درجات )
سبب ذلك لكل منهما ؟
ج) أولاً : تناول القاص ( محمد خضير ) الحرب في قصصه ولاسيّما في مجمو عاته القصصية الثلاث
( درجتان )
الأولى ، فما الآثار التي تتركها الحرب على الواقع ؟
( درجتان )
ثانياً : ما المراد ب ( الذروة ) و ( الخاتمة ) على وفق دراستك لعناصر الحبكة في الرواية؟
س٦ : أ) بمن تمثل التغيير في مسرحية ( محمد علي الخفاجي ) ؟ وكيف كان الحل ؟ استشهد له من :
( ٥ درجات )
( البداية ... إلى ... مَن للعدل إمام غيرك ) .
( درجتان )
ب) بمَ اختلف جماعة المهجر الشمالي عن جماعة المهجر الجنوبي في موضوع التحرر والثورة ؟
ج) ١) للشاعر ( علَي محمود طه المهندس ) قصيدة بعنوان ( اللّٰه والشاعر ) ، كيف كان شكلها ؟
( ٤ درجات )
ولماذا ؟ اكتب له مقطعاً يصوّر مأساة الإنسان وطول شكاته .
( ٤ درجات )
٢) عرّف اثنين : الجمود الفني ، الأمثال ، ملحمة جلجامش .
( ٢٠ درجة )
الإنشاء :
س٧ : اكتب في أحد الموضوعين الاتيين :
١) قال الإمام علي ( عليه السلام ) : ( ما رام امرؤ شيئاً إلاّ وصل إليه أو دونه ) .
اسعَ وكد فإن تعبت فلا تقف ، واصبر وثابر فالنجاح محقق .
مدى الدهر أنّ اللّٰه اقسم بالقلم
٢) قال الشاعر : كفى قلمُ الكتّاب عزاً ورفعةً
القلم سفير العقل ورسوله الأنبل وترجمانه الأفضل .
