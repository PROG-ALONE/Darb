الأدب والنصوص :
( ٤٠ درجة )
س ٤ : أ) ما يُعدَّ ( ميخائيل نعيمة ) ؟ وما عنوان قصيدته ؟ اكتب له ثلاثة ابيات منها مضبوطة بالشكل .
( ٥ درجات )
ب) أجب عن أولاً أو ثانياً :
( ٣ درجات )
أولاً : إلى أيّ مذهب ( أدونيس ) أقرب ؟ وعمّ يكشف التحليل البنيوي لقصيدته ( رؤيا ) ؟
ثانياً : بِمَ ابتدا ( علي جواد الطاهر ) مقالته ؟ وما الفكرة الرئيسية منها ؟
ج) ١) متى عرف العرب المسرحية ؟ ومَنْ أول من كتب فيها ؟ وما عنوان مسرحيته ؟
( ٣ درجات )
٢) ما المقصود ب ( الرباعية ) ومَن مِنَ الشعراء نظم قصيدته على هذا الفن ؟
( ٣ درجات )
س٥ : أ) للشاعر ( علي الشرقيّ ) قصيدة في منهجك ، ما عنوانها ؟ ثمّ مثل له بالأفكار الاتية :
( ٥ درجات )
١) أفصحَ عن أمرٍ صريح يحثَ على العناية بالقلم ونصرة العلم .
٢) استعمل أسلوب القصر في قصيدته .
ب) أجب عن أولاً أو ثانياً :
( ٤ درجات )
أولاً : ما الأساليب البلاغية التي استخدمها ( الحبّوبي ) في موشحته ؟
ثانياً : ما أهم خصائص السيرة ؟ اذكرها .
ج) علل لاثنتين فقط :
( ٤ درجات )
١) تلحُّ الشاعرة ( فدوى طوقان ) في طلب الحب .
٢) القصّة القصيرة ليس من شأنها تنمية أحداث وبيئات وشخوص .
٣) عرف العرب الخطابة قديماً .
س٦ : أ) ما مميزات ( واحدة ) ممّا يأتي؟
( ٣ درجات )
١) الرواية النفسية .
٢) الرواية التأريخية .
ب) هل وظّف ( الجواهريّ ) المكان في قصيدته ( آمنت بالحسين ) ؟ وكيف ؟
( ٣ درجات )
ج) ١) استطاع ( السيّاب ) الموازنة الخلاقة بين منحنيين أدبيين ، ما هما ؟ وما يظهر فيهما ؟
( ٤ درجات )
٢) أين تمظهرت جماليات قصة ( الباب الاخر ) ل ( فؤاد التكرلي ) ؟
( ٣ درجات )
الإنشاء :
( ٢٠ درجة )
س٧ : اكتب في أحد الموضوعين الآتيين :
١) قال تعالى : ( وَوَصَّيْنَا الْإِنسَنَ بِوَالِدَيْهِ حُسْنًا وَإِن جَهَدَاكَ لِتُشْرِكَ بِي مَا لَيْسَ لَكَ بِهِ عِلْمٌ فَلَا نُطِعْهُمَا ) .
اكتب في مكانة الوالدين ووجوب طاعتهما إلاّ فيما حرّم اللّٰه تعالى .
٢) قال الشاعر : لمّا عفوت ولمْ أحقدْ على أحدٍ
أرحتُ نفسي من همّ العداواتِ
العفو والتسامح هو الطريق الأمثل للعيش بسلام وأمان .
