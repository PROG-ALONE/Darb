# محاكاة السنة الدراسية الكاملة (طالب السادس العلمي)

تفتح التطبيق الحقيقي في Chromium (Playwright)، وتزيّف الساعة يومًا بيوم من ١ تشرين الأول ٢٠٢٦ حتى ١٢ حزيران ٢٠٢٧،
وفي كل يوم دراسة تفعل ما يفعله الطالب **بالنقر على الأزرار نفسها**:

1. تفتح «الخطة» وتأخذ مواضيع اليوم من `planToday()`.
2. لكل موضوع: تمرّ على كل تبويب (شرح، تعاريف، قوانين، تعليلات، فراغات، أمثلة، مسائل، حفظ)، تحل المسائل وتقيّم نفسها، ثم تختبر الموضوع (وتعيده إن لم تتقن).
3. المراجعة المتباعدة: تفتح تبويب المراجعة وتجري اختبار كل موضوع مستحق من زرّه.
4. اختبار الفصل حين يُفتح قفله.
5. أول يوم دراسة من كل شهر (من تشرين الثاني): امتحان شهري لكل مادة.
6. من شباط: محاكاة وزارية كاملة كل سبت لمادة بالتناوب (مع التقييم الذاتي للأسئلة المفتوحة).
7. كل أحد: جولة على كل التبويبات والنوافذ والسجلات والبنوك.

بعد كل شاشة تفحص: `undefined` / `NaN` / `[object` / وسوم HTML ظاهرة كنص / أخطاء JavaScript.
قدرة الطالب تتحسن تدريجيًا (٦٢٪ → ٩٣٪)، ويغيب ٥٪ من الأيام عشوائيًا.

```bash
pip install playwright && python3 -m playwright install chromium
python3 official-exams/year-sim/sim.py      # ~٣–٤ دقائق
```
النتيجة في `official-exams/year-sim/sim_out.json` (سجل كل يوم + الحصيلة + المشكلات).
